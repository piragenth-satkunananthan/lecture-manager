# Zoom Meeting SDK for Linux

 __Copy for LLM

[ View as Markdown](/docs/meeting-sdk/linux.md)

**Meeting SDK usage policy**

The Meeting SDK is designed for human use cases and does not support bots or AI notetakers. To build an AI notetaker application or access realtime media, use [Zoom RTMS (Real-time media streams)](/docs/rtms/).

The Zoom Meeting Software Development Kit (SDK) for Linux lets you integrate
the Zoom meeting and webinar experience with your app. The Meeting SDK for
Linux is structured as a command-line interface (CLI) based application. The
Meeting SDK for Linux supports meeting services only, and does not currently
support messaging.

The Meeting SDK for Linux naturally supports over a dozen major languages. Some core features are described in this developer doc, and additional features are described in the [Meeting SDK reference guides  __](https://marketplacefront.zoom.us/sdk/meeting/linux/index.html).

Use the [Meeting APIs](/docs/api/meetings/) to get data from current, past, or future meetings to enhance the SDK's meeting experience. To use specific API endpoints with your SDK app, choose the endpoints' scopes on your app configuration page.

We enforce a required minimum version of the Meeting SDK. See our [SDK minimum version policy](/docs/meeting-sdk/minimum-version/) for details.

The Meeting SDK follows the Zoom license model. See [Zoom Meetings  __](https://www.zoom.com/en/products/virtual-meetings/),[Zoom Webinars  __](https://www.zoom.com/en/products/webinars/), and the[Zoom ISV Partner Program  __](https://www.zoom.com/en/isv/)for details.

Running the Meeting SDK for Linux in a cross-architecture emulated environment
can cause significant performance degradation and unreliable behavior.
QEMU/Rosetta emulation is not a supported or dependable way to run the Meeting
SDK for Linux. Any emulated environment should match the host architecture.

In the next section, we'll walk you through setting up a development environment for Meeting SDK for Linux platform, and give you some [hands-on experience](/docs/meeting-sdk/linux/get-started/download/).
