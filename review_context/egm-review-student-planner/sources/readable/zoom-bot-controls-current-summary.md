# Zoom bot controls - current page summary

Source: https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0088381
Retrieved: 2026-11-08 through the web page reader. The saved HTTP response is a loading shell without the article body.

Zoom distinguishes Marketplace integrations, including the Meeting SDK and RTMS, from automated use of its Native or Web Apps. Hosts can control Marketplace SDK apps through an allow/block list; unpublished apps cannot join meetings outside their developer account. Zoom's Web App has built-in detection for automated or suspicious participants, enabled by default and not configurable off. Other controls include sign-in requirements, email-domain restrictions, waiting rooms, and a dashboard showing apps attempting to join or being blocked. Waiting rooms can auto-admit signed-in users while leaving guests for host review.
