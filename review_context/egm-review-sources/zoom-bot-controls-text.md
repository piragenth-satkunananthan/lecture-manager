# Blocking bots from joining meetings and webinars

Source: https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0088381

Zoom provides security features and built-in bot protection to help block unauthorized participants or bots. The page describes two paths:

* Official paths include Zoom Marketplace integrations such as the Meeting SDK and RTMS, which let meeting hosts control which bots are allowed.
* Unofficial paths include automated use of the Zoom Native or Web Apps.

The Meeting SDK block/allow list controls which SDK apps can join. Apps that are not published to the Zoom Marketplace cannot join meetings outside their developers' account.

Zoom Web App includes built-in detection that intercepts automated or suspicious participants. The page says this protection is enabled by default and cannot be turned off.

Other controls include requiring users to sign in, restricting access by email domain, and placing guests in the waiting room for host review. Signed-in users can be configured for automatic admission; guests may remain in the waiting room until admitted.

The Meetings app dashboard shows apps attempting to join, joining, or being blocked.
