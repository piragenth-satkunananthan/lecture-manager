# Lecture Manager Blueprint

## System Overview

Lecture Manager is a planned student planner for assignments and Zoom lectures. The project idea is to collect assignment posts from a WhatsApp group, join and record lectures from shared Zoom links, and show assignments and lectures together in a calendar. These are planned capabilities; the current repository contains no implementation files.
